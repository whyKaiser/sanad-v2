# سَنَد

نموذج هاكاثون عربي لحفظ وثائق السفر ومراجعتها من مصدرها. جميع الحالات والوثائق اصطناعية. لا يحتاج مفتاح API.

## تجربة المشروع

سجّل الدخول واضغط **تحميل الحالات التجريبية**. افتح عمر سالم لاسترجاع النسخة، يوسف رحيم لمراجعة اختلاف الاسم، ليلى حسن للوثيقة البديلة، وآدم نور لغياب المستند. إرفاق وثيقة يتيح تحميل عينة وقراءتها محليًا. العينة تخص عمر، فلا تحفظها في حالة أخرى إلا لاختبار الاختلافات.

المساعد يغطي النسخة الأصلية والبديلة والاختلافات والملخص والمصدر والجنسية المكتوبة. النموذج الدلالي يحتاج تنزيلًا أول مرة قد يستغرق دقائق. الاستعلام المباشر يعمل أثناء عدم توفره. يمكن تفعيل **Groq** بمفتاح حسابك لصياغة مسودات عربية مرتبطة بالمصادر؛ [خطوات التفعيل وحدود الاستخدام](docs/GROQ.md). الوضع المحلي لا يحتاج مفتاحًا، ويظل متاحًا عند تعطل Groq. استضافة Sites وتسجيل الدخول في ChatGPT منفصلان عن مزود الذكاء الاصطناعي.

## التشغيل المحلي

يتطلب Node.js 22.13 أو أحدث. من مجلد المشروع:

```sh
npm ci
node scripts/prepare-ai.mjs
npm run build
node scripts/init-local-db.mjs
npm run dev -- --host 127.0.0.1
```

افتح `http://localhost:5173`. يمكن استخدام ملف `Start-Sanad.ps1` المرفق. يحفظ التطوير البيانات تحت `.wrangler/state`. التهيئة المحلية لا تحذف البيانات. الدخول المحلي التجريبي خاص بـ loopback، أما النشر فيعتمد على تسجيل دخول Sites. لا تنشر خادم التطوير.

إذا تعطل اختصار npm على Windows:

```powershell
& 'C:/Program Files/nodejs/node.exe' 'C:/Program Files/nodejs/node_modules/npm/bin/npm-cli.js' run build
```

## الاختبارات

```sh
npm run typecheck
npm test
```

بعد تشغيل التطبيق محليًا وتحميل الحالات التجريبية، اختبارات التكامل تنشئ حالات اختبار إضافية:

```sh
node node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file tests/tenant-fixtures.sql
node --import tsx --test tests/api.test.ts tests/tenant.test.ts
```

## المكونات

React/Vinext للواجهة والخادم، D1 للحالات والوثائق والإجراءات ولقطات الحزم، R2 للملفات، Tesseract لقراءة الصور، وTransformers.js للفهم الدلالي المحلي. `lib/sanad/server.ts` يتحقق من المستخدم وملكية كل سجل، ويمنع الكتابة بإصدار مراجعة قديم. تحفظ الحزم لقطة ثابتة، وتظل الملفات الأصلية دون استبدال.

## حدود النسخة

التكامل الحكومي والقنصلي محاكاة. المصدر وصف مدخل، وبصمة SHA-256 ليست إثبات أصالة. الجنسية نقل لما ورد في الوثيقة، وليس قرارًا بشأن الشخص. لا يقرر سَنَد الإبعاد أو المنع من الدخول، ولا يستعيد صورة لم تحفظ.

PDF للحفظ والمراجعة اليدوية. القراءة الآلية للصور الإنجليزية/اللاتينية ومنطقة MRZ. نجاح العينة الاصطناعية لا يثبت دقة عامة على جوازات حقيقية. الإنتاج الحكومي يحتاج اعتماد البنية والصلاحيات وسياسات الاحتفاظ والنسخ الاحتياطي والأمن والتحقق من المصادر.
