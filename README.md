# سَنَد

تطبيق عربي مستقل لمراجعة وثائق السفر وحفظ مرجعها. نموذج هاكاثون ببيانات اصطناعية، مستضاف على Cloudflare، وله صفحة دخول خاصة باسم مستخدم وكلمة مرور. لا يتطلب حساب ChatGPT. يعمل المساعد محليًا، ويمكن تفعيل Groq لصياغة مسودات مرتبطة بالمصادر.

[فتح سَنَد](https://sanad.songokualshareef.workers.dev) · [المستودع الخاص](https://github.com/whyKaiser/sanad) · [وثيقة الحل](presentation/SANAD-solution.pdf) · [عرض المشروع](presentation/SANAD-final-pitch.pptx)

## تجربة المشروع

سجّل الدخول واضغط **تحميل الحالات التجريبية** إذا كانت القائمة فارغة. افتح عمر سالم لاسترجاع النسخة، يوسف رحيم لمراجعة اختلاف الاسم، ليلى حسن للوثيقة البديلة، وآدم نور لغياب المستند. إرفاق وثيقة يتيح تحميل عينة وقراءتها محليًا. العينة تخص عمر؛ إرفاقها بحالة أخرى يختبر الاختلافات.

المساعد يغطي النسخة الأصلية والبديلة والاختلافات والملخص والمصدر والجنسية المكتوبة. النموذج الدلالي يحتاج تنزيلًا أول مرة. الاستعلام المباشر متاح أثناء ذلك. يمكن تفعيل **Groq** بمفتاح حسابك؛ [التفعيل وحدود الاستخدام](docs/GROQ.md). عند تعطل المزود يبقى مسار الإجابة من السجل متاحًا.

## التشغيل المحلي

يتطلب Node.js 22.13 أو أحدث. من مجلد المشروع:

```sh
npm ci
npm run setup:login
npm run db:migrate:local
node scripts/prepare-ai.mjs
npm run dev
```

افتح `http://localhost:5173`. بيانات الدخول الخاصة تُنشأ في `work/login-private.txt`، وتُحفظ تجزئة كلمة المرور في `.env`. كلاهما مستثنى من Git. لإضافة Groq، ضع `GROQ_API_KEY` داخل `.env` مع إبقاء إعدادات الدخول الموجودة، ثم أعد تشغيل الخادم. ملف `.env.example` مرجع للإعدادات فقط؛ لا تستبدل به ملفًا قائمًا.

يمكن استخدام `Start-Sanad.ps1`. يحفظ التطوير البيانات تحت `.wrangler/state`، ولا تحذف التهيئة البيانات. لتغيير كلمة المرور: `npm run setup:login -- --rotate`؛ ثم أعد تشغيل التطوير أو انشر الأسرار المحدثة. التغيير يبطل الجلسات القديمة في البيئة المحدثة.

لمعاينة البناء النهائي محليًا: `npm run build` ثم `npm start`. يستخدم ملفات البناء وأسرار `.env` المحلية، ويظل النشر الفعلي خطوة منفصلة.

إذا تعطل اختصار npm على Windows:

```powershell
& 'C:/Program Files/nodejs/node.exe' 'C:/Program Files/nodejs/node_modules/npm/bin/npm-cli.js' run dev
```

## النشر المستقل

ملف `wrangler.jsonc` يحدد Worker وقاعدة D1. للنشر على حساب آخر، غيّر `account_id` و`database_id` بعد إنشاء قاعدة خاصة بك. لا تنفذ ترحيلات على قاعدة لا تملكها.

```sh
npx wrangler login
# عند إعداد حساب جديد فقط:
npx wrangler d1 create sanad-db
# حدّث معرّفات الحساب والقاعدة في wrangler.jsonc، ثم:
npm run deploy
node scripts/publish-secrets.mjs
```

أمر النشر يبني التطبيق، ويطبق ترحيلات D1 ثم ينشر Worker وأصوله. أمر الأسرار يقرأ `.env` محليًا ويرسل القيم إلى Cloudflare عبر الإدخال القياسي دون طباعتها. قبل تهيئة أسرار الدخول، لا تتيح النسخة الوصول إلى الحالات. خذ الرابط الفعلي من نتيجة Wrangler. GitHub يحفظ المصدر؛ النشر يتم بالأمر أعلاه ولا يعمل تلقائيًا بمجرد رفع commit.

## الاختبارات

```sh
npm run typecheck
npm test
npm run build
```

بعد تشغيل التطبيق محليًا، حمّل الحالات التجريبية من الواجهة ثم جهّز سجل مستخدم آخر لاختبار العزل:

```sh
npx wrangler d1 execute DB --local --file tests/tenant-fixtures.sql
npm run test:integration
```

الاختبارات تستخدم بيانات الدخول المحلية، وتنشئ سجلات اصطناعية وملفًا بحجم 5 ميغابايت. لا توجهها إلى بيئة فعلية. [سجل التحقق وحدوده](docs/VERIFICATION.md).

## المكونات والبيانات

React/Vinext للواجهة والخادم، D1 للحالات والوثائق والإجراءات ولقطات الحزم والجلسات، Tesseract لقراءة الصور، Transformers.js للفهم الدلالي المحلي، وGroq اختياري للصياغة. الملفات محفوظة داخل D1 في أجزاء بحجم 256 KiB بحد 5 MiB للملف؛ لا تتطلب هذه النسخة R2.

الدخول الحالي لحساب مراجعة واحد، مع جلسات عشوائية مدتها 8 ساعات وتجزئة لكلمات المرور وتقييد محاولات الدخول. ملفات الارتباط `HttpOnly` و`SameSite=Strict` و`Secure` على HTTPS. كل طلب يتحقق من المستخدم وملكية السجل، والتعديلات تتحقق من مصدر الطلب وإصدار المراجعة. الحزم تحفظ لقطة ثابتة، والوثائق الأصلية لا تُستبدل. لا توجد واجهة لإدارة عدة مستخدمين في هذه النسخة.

## حدود النسخة

التكامل الحكومي والقنصلي محاكاة. المصدر وصف مدخل، وبصمة SHA-256 ليست إثبات أصالة. الجنسية نقل لما ورد في الوثيقة، وليست قرارًا بشأن الشخص. لا يقرر سَنَد الإبعاد أو المنع من الدخول، ولا يستعيد صورة لم تحفظ، ولا يضمن قبول القنصلية للوثيقة.

PDF للحفظ والمراجعة اليدوية. القراءة الآلية للصور الإنجليزية/اللاتينية ومنطقة MRZ. نجاح العينة الاصطناعية لا يثبت دقة عامة على جوازات حقيقية. الإنتاج الحكومي يحتاج اعتماد البنية والصلاحيات وسياسات الاحتفاظ والنسخ الاحتياطي والأمن والتحقق من المصادر. حجم التخزين وحصة Groq خاضعان لحدود حسابك.

## المشاركة

المشروع يعرض حلًا للتحدي ضمن أمن المنافذ، دون ضمان درجات أو فوز. طُوّر بمساعدة برمجية بالذكاء الاصطناعي. يتحقق الفريق من سياسة المساعدة وأهليته مع المنظم قبل تقديم تعهد الأصالة، ويفهم المشروع ويطوره ويُفصح وفق التعليمات. لم نوقّع أو نقدم أي تعهد نيابة عن الفريق.
