## ما يعمل

| الوحدة | التنفيذ |
|---|---|
| سَنَد | حفظ صور/PDF، OCR محلي، مراجعة الحقول، معلومات المسافر، تفاصيل الدخول والخروج، مسودة حزمة المراجعة، ما قبل الوصول بمحاكاة واضحة |
| موثوقية السجلات | سجل قبل/بعد، هوية الموظف من الجلسة، سبب التغيير، توقيعات HMAC-SHA256 متسلسلة، مطابقة السجل مع البيانات، رفض الكتابة عند فشل السلامة |
| توقع الإقبال | نموذج مدرب على بيانات CBP العامة، توقع 24 ساعة، اختبار زمني مستقل، نطاق خطأ تجريبي، CSV ومحاكاة الكاونترات |
| التخطيط التشغيلي | محاكاة الملفات المتبقية حسب الموارد والوارد والمدة، شرح الحساب، فصل انتظار القنصلية عن المراجعة الداخلية، حفظ قرار المشرف وافتراضاته |
| الحماية | أربعة أدوار، تحقق على الخادم، جلسات قابلة للإلغاء، منع الحفظ فوق نسخة قديمة، تحكم بخروج البيانات إلى Groq، مؤشرات اختلاف الوثائق وتكرار الملفات |

الصورة لا تثبت الجنسية وحدها. المؤشرات تستدعي المراجعة؛ لا تثبت تزويرًا أو مخالفة. محاكاة مراجعة الملفات ومحاكاة الكاونترات حسابيتان بمعاملات المستخدم. توقع الإقبال نموذج مدرب مستقل على بيانات أمريكية تاريخية؛ لا يثبت أداءً سعوديًا أو أثرًا ميدانيًا. راجع [منهجية التدريب والتقييم](ml/README.md).

## تحديث التنبؤ — 15 سبتمبر 2026

أُصلحت الفجوات الزمنية باستخدام الساعات الفعلية؛ البيانات المفقودة ليست صفرًا. توقعات 1–24 ساعة لا تعتمد على أعداد مستقبلية أو تغذية تكرارية مختلفة بين الواجهة والتصدير. التقييم على 6,773 ساعة: MAE = 86.92 مقابل 93.97 للمرجع البسيط، تحسن 7.50% في متوسط الخطأ وليس نسبة دقة.

النموذج والتاريخ مدمجان في الخادم؛ لا يحتاج تشغيل Python أو إضافة مفتاح جديد. Python مطلوب لإعادة التدريب فقط. راجع `ml/requirements.txt` و`ml/evaluation.json`.

## تشغيل محلي

Node.js 22.13 أو أحدث، npm. التطبيق React 19 وTypeScript، يعمل عبر Vinext على Cloudflare Workers وD1. يتطلب تثبيت الحزم اتصالًا بالإنترنت؛ ملفات OCR والبحث الدلالي موجودة في `public/ai`.

```sh
npm ci
npm run setup:login
npm run db:migrate:local
npm run dev
```

افتح `http://localhost:5174`. الحساب الأول في `work/login-private.txt`. لإضافة حالات العرض وحسابات الأدوار بعد تشغيل الخادم:

```sh
node scripts/setup-demo.mjs
```

الحسابات الأربعة في `work/team-private.txt`. ملفات الحسابات و`work` و`.env` مستثناة من Git. لا ترفعها ضمن تسليم المشروع. لا تستخدم بيانات الأشخاص في صور المراجع.

## النشر المستقل

الإعداد خاص بـ Worker `sanad-v2` وقاعدة `sanad-v2-db`. سكربت الحماية يمنع استهداف سَنَد الأصلي. عند النقل لحساب Cloudflare آخر أنشئ قاعدة ثانية ثم عدّل `account_id` و`database_id` في `wrangler.jsonc`. migrations SQL هي المرجع، وتشمل triggers لا ينشئها Drizzle تلقائيًا.

```sh
npx wrangler login
npm run build
npm run db:migrate:remote
node scripts/publish-secrets.mjs
npx wrangler deploy --config dist/server/wrangler.json
```

لتجهيز العرض المنشور، عيّن `SANAD_TARGET_URL` إلى رابط سَنَد ٢ ثم شغّل `node scripts/setup-demo.mjs`. السكربت يسمح بالعنوان المحدد لهذه النسخة أو loopback فقط؛ عدّله صراحة عند نقل الاستضافة.

Groq اختياري: أضف المفتاح إلى `.env` فقط، انشر الأسرار، ثم فعّل السماح من «الحسابات والحماية». الإعداد الافتراضي يمنع استخدام المزود الخارجي. OCR والبحث المحلي يعملان دون مفتاح. في رابط العرض الحالي فُعّل Groq بطلب صاحب المشروع، واختُبرت صياغة فعلية. الواجهة تفرّق بين غياب المفتاح وإيقاف السياسة؛ وجود المفتاح ليس ضمانًا لعدم بلوغ حد الاستخدام.

## نطاق النسخة

سَنَد الأصلي مستقل: مجلد وWorker وقاعدة وجلسة دخول مختلفة. لا ترقية تلقائية للبيانات القديمة. هذا نموذج هاكاثون قابل للتجربة، ولم يحصل على اعتماد أمني أو ربط بوزارة الداخلية أو الخارجية أو القنصليات. الربط والمطابقة البيومترية الرسمية تتطلب نطاقًا وموافقات واختبارات مستقلة قبل استخدام بيانات حقيقية.
