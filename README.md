> الحساب منشور عمدًا: هذه **نسخة عرض قابلة للاستبدال**، وكل ما بداخلها **بيانات اصطناعية** — أسماء ووثائق ملفّقة لغرض العرض، لا تخص أشخاصًا حقيقيين. لا تدخل أي بيانات حقيقية، ولا تستخدم هذه البيانات على أي تثبيت آخر.

جرّب بخمس دقائق: افتح حالة «يوسف رحيم» → قارن الوثيقة بسجل الدخول → افتح **موثوقية السجلات** واضغط `+` على أي حدث لترى الخانة قبل وبعد ومن عدّلها ولماذا → افتح **التخطيط التشغيلي** وقارن سعة مراجع واحد بمراجعَين.

## 💡 الفكرة

بدأت من مشكلة وصفها موظف في إدارة الوافدين: تصل حالة للمغادرة وأصل الجواز غير متاح، فتحتاج الجهة نسخة من المستند تساعدها في مراجعة القنصلية لإصدار وثيقة سفر. البيانات النصية وحدها لا تعوّض النسخة.

سَنَد يحفظ **نسخة الوثيقة ومصدرها** ويربطها بملف الدخول، ويوثّق **من عدّل وماذا غيّر ولماذا**، ويحاكي **أثر توزيع الموظفين** على الملفات المتبقية — ليرجع لها الموظف وقت الحاجة، ويراجع المشرف ويعتمد.

> الصورة لا تثبت الجنسية وحدها، والتطبيق لا يصدر قرار إبعاد ولا يستنتج جنسية من وجه أو اسم. المؤشرات تستدعي مراجعة بشرية، ولا تثبت تزويرًا أو مخالفة.

## 🏗️ البنية التقنية

```
React 19 + TypeScript — واجهة عربية RTL على Vinext
│
├── الخادم
│     Cloudflare Workers + D1 (SQLite)
│     Drizzle ORM — وملفات migrations SQL هي المرجع
│     (تشمل triggers لا ينشئها Drizzle تلقائيًا)
│
├── سلامة السجلات
│     HMAC-SHA256 متسلسل على كل حدث تعديل
│     كل كتابة تمر بـ beginMutation / finishMutation
│     رفض الكتابة إذا انكسرت السلسلة
│
├── الذكاء الاصطناعي
│     Tesseract — قراءة الصور على الجهاز
│     Transformers.js — بحث دلالي محلي
│     Groq — اختياري، مغلق افتراضيًا، المفتاح في أسرار الخادم
│
└── التنبؤ
      تدريب في Python → تصدير شجرة رقمية مضغوطة
      الاستنتاج داخل الخادم TypeScript — لا Python وقت التشغيل
```

**قرارات تصميم أساسية:**

- **السبب قبل الحفظ:** لا تعديل بدون سبب مكتوب، والهوية تؤخذ من الجلسة لا من حقل يكتبه المستخدم — فالسجل يصلح للمراجعة لا للتجميل.
- **المحاكاة معلنة:** الربط الحكومي والقنصلي **محاكاة واضحة** داخل الواجهة، مفصولة بصريًا عن الوظائف الفعلية. لا اتصال فعلي بأي نظام جهة.
- **الخارج مغلق افتراضيًا:** المعالجة المحلية تعمل بلا مفتاح. تفعيل المزوّد الخارجي قرار صريح من مسؤول المساحة، والواجهة تفرّق بين *غياب المفتاح* و*إيقاف السياسة*.
- **عزل النسخة:** سَنَد الأول مستقل تمامًا — مجلد و`Worker` وقاعدة وجلسة دخول مختلفة، وسكربت حماية يمنع استهدافه بالخطأ.

## 🚀 التشغيل المحلي

المتطلبات: `Node.js 22.13+` و`npm`. ملفات القراءة الضوئية والبحث الدلالي موجودة في `public/ai`؛ تثبيت الحزم يحتاج اتصالًا.

```bash
npm ci
npm run setup:login        # ينشئ حساب المسؤول ويحفظه في work/ — مستثنى من الرفع
npm run db:migrate:local
npm run dev                # http://localhost:5174
```

لإضافة حالات العرض وحسابات الأدوار الأربعة بعد تشغيل الخادم:

```bash
node scripts/setup-demo.mjs   # البيانات تُحفظ في work/team-private.txt فقط
```

> مجلد `work/` وملفات `.env` مستثناة من `Git` ولا تُرفع ضمن أي تسليم. لا تستخدم بيانات أشخاص حقيقيين في صور المراجعة.

### التحقق

```bash
npm run typecheck
npm test
npm run build
npm run test:integration   # Miniflare + قاعدة محلية مستقلة لكل تشغيل
npm run lint
```

### النشر

```bash
npx wrangler login
npm run build
npm run db:migrate:remote
node scripts/publish-secrets.mjs
npx wrangler deploy --config dist/server/wrangler.json
```

الإعداد خاص بـ `Worker` باسم `sanad-v2` وقاعدة `sanad-v2-db`. عند النقل لحساب آخر أنشئ قاعدة ثانية ثم عدّل `account_id` و`database_id` في `wrangler.jsonc`.
