# Reproducible historical arrival forecast

This module evolves the submitted CBP forecasting work into the SANAD application.
No original pickle or virtual environment is required at runtime. Training runs in
Python, exports a compact numeric tree artifact, and inference runs on the existing
authenticated TypeScript server. CSV and charts use the same prediction function.

## Reproduce

```sh
python -m venv .venv
# Activate the environment for your platform.
pip install -r ml/requirements.txt
python ml/train_forecast.py
npm test
```

Data: `ml/data/cbp.parquet`, 36,089 aggregate records from 23 US airports / 35
airport-terminal pairs. It contains no passenger identities. Target:
`non_us_citizen_count`, not all passengers or Saudi expatriate case counts.

Source: [Henry Williams, US Airport Security & Immigration Wait Times](https://huggingface.co/datasets/digitalhen/us-airport-wait-times), subset `cbp`.
Upstream: [US CBP](https://awt.cbp.gov/). Publisher license: **CC BY 4.0**;
attribution retained in the screen and model metadata. The unchanged downloaded
data hash and coverage are recorded in `evaluation.json`. Derived features and
model artifacts are generated by this script.

## Method and scope

- Exact local timestamps replace row-offset daily/weekly lags. Missing != zero.
- Features: calendar, site, exact counts 24/48/168 hours ago, summaries of the
  same hour over the preceding 28 days. All count inputs are at least 24 hours
  older than the target, so any horizon 1–24 needs no recursive predicted counts
  or observed counts from inside the future window.
- Selection training ends 2026-08-12; validation is Aug 12–25; final test begins
  Aug 26. Candidate settings and blending are selected using validation only.
- The selected candidate is fitted on the pre-test history; that exact fitted
  artifact is deployed. Final test scores remain associated with that artifact.
- Counts at future target times are used only for scoring / historical comparison.
  Data publication latency at real forecast issuance is not verified. This is a
  historical demonstration, not proof of live accuracy or annual seasonality.
- Median/mean calculations ignore absent readings rather than filling with zero.
- Sites with fewer than 48 observations or 7 observed days get explicit coverage
  status. Prediction additionally checks available history at the chosen origin,
  chronological scope, and a 48h maximum gap before issuance.
- Model selection test and per-site metrics: `evaluation.json`; golden Python
  fixtures: `fixtures.json`. TypeScript tests require parity to 1e-7.
- The 80% absolute residual band is calibrated on validation; final-test empirical
  coverage is shown separately. It is not a guaranteed interval for any one hour.
- This does not predict consular processing, nationality, immigration violations,
  or a person's security risk.

## Operations and integration

`GET /api/forecast/sites`; authenticated `POST /api/forecast`,
`POST /api/forecast/csv`, and `POST /api/forecast/simulation`.
View-only accounts may run these read-only calculations. Existing session and
origin checks apply. No case records or government systems are changed.

Example body: `{"siteId":"JFK|Terminal 4 (IAT)","asOf":"2026-09-12 23:00","horizon":24}`.
Times are the airport's source local wall clock, not Saudi time or universal UTC.
The default origin is the latest observation, clearly labeled historical.
The model does not invent current flight schedules or silently extend data dates.

Capacity simulation is a separate deterministic scenario, for dedicated counters
serving the forecasted passenger category. Counters, minutes/passenger, and initial
queue are explicit assumptions. Hourly queue = max(0, previous queue + arrivals -
capacity); capacity/hour = counters * 60 / minutes per passenger. This is not a
causal estimate of real staffing impact. No automated staffing action occurs.

Historical data is intentionally bundled server-side for a reproducible demo.
Updating the source requires retraining, chronological validation, parity tests,
and deployment. No external inference provider or Groq key is needed here.
