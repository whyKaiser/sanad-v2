# سجل التحقق

تاريخ الفحص: 11 سبتمبر 2026. بيئة Windows، Node.js 25.6، متصفح Codex، بيانات محلية اصطناعية.

- بناء النسخة النهائية نجح، وفحص TypeScript نجح.
- 19 اختبارًا آليًا نجحت: دورة إنشاء حالة وإرفاق ومراجعة، منع التكرار، رفض الإصدار القديم، ثبات الحزمة بعد تعديل الحالة، حفظ البيانات، التحقق من التواريخ، رفض الملف غير المدعوم، تهريب HTML، منع طلبات غير المصادق عليها، منع انتحال ترويسات التطوير، رفض المصدر الخارجي، وعزل حالات ووثائق وحزم مستخدم آخر.
- OCR اختُبر على ملف PNG الفعلي ذي العمودين. استُخرجت الحقول الخمسة المطابقة للعينة، وربطت بمواضعها. اختُبرت القراءة أيضًا داخل المتصفح، وليست نتيجة محاكاة.
- النموذج الدلالي شُغّل فعليًا في Web Worker بعد تنزيله. استُخدم محرك ONNX محلي لتجنب اعتماد تشغيل WASM على CDN آخر. اختُبر سؤال عربي مختلف الصياغة عن أمثلة الواجهة، ومرجع الاسم فتح موضعه في الصورة. اختُبر الامتناع عن سؤال سعر الذهب خارج الملف.
- أضيف فحص صريح لصياغة السؤال بعد اكتشاف تصنيف دلالي غير دقيق. النموذج يدعم مقاصد محددة ولا يضمن فهم جميع الصياغات.
- فحص الهاتف: عمود واحد، الحقول والأزرار متاحة، ولا يوجد تجاوز أفقي لجسم الصفحة عند عرض يقارب 390 بكسل.
- WebMCP: أداة قراءة الحالات أعادت الحالة المطلوبة بنجاح. أداة التنقل فتحت ملف ليلى بنجاح، ولا ندعي تغطية توافق كل وكلاء المتصفح.
- وثيقة الحل: ثلاث صفحات عُرضت وفُحصت. العرض: عشر شرائح، فحص هيكل الملف والهندسة والاستيراد نجح، والشرائح عُرضت وفُحصت. لم يُختبر العرض داخل تطبيق PowerPoint نفسه.

حدود هذه النتائج: ليست اختبار اختراق مستقلًا، ولا قياسًا لدقة OCR على وثائق حقيقية، ولا تجربة تشغيل حكومية أو إثباتًا لخفض مدة التوقيف. الاتصالات الحكومية محاكاة، وأوزان النموذج تحتاج اتصالًا أول مرة. تأكيد النشر منفصل عن اختبارات التطوير المحلية.

## إضافة Groq

أضيفت ثمانية اختبارات مع استجابات بديلة للمزود: غياب المفتاح، عدم كشفه في إعدادات الواجهة، الطلب المخول بأقل بيانات، صحة معرفات المراجع، رفض مصدر مخترع، تجاوز الحصة ورفض المفتاح وانقطاع الخدمة، تصنيف سؤال جديد، الامتناع عن قرارات الجنسية والإبعاد والبيانات الحقيقية، والإجابة المبتورة أو غير الصالحة. نجحت الاختبارات الثمانية مع اختبارات المنطق الثلاثة عشر. لا نعد الاستجابات البديلة اختبارًا حيًا للمزود.

بعد إضافة المفتاح، نجح اختبار Groq الفعلي بطلبي HTTP 200: توليد ملخص بخمسة مراجع ورفض سؤال خارج الملف. اختبار الخادم كشف أن Workers لا يقبل `redirect: "error"`؛ استُبدل بـ `manual` مع رفض استجابات التحويل، دون اتباعها أو إرسال بيانات الاعتماد إلى وجهة أخرى. أضيف تحقق يمنع تكرار الخطأ، ونجحت اختبارات Groq الثمانية. ثم نجح مسار `/api/assistant` في بيئة التطوير مع `mode: "generative"` والمراجع والنص السابق للصياغة. اختُبر التبديل إلى الإجابة المحلية. المفتاح محفوظ كسرّ للاستضافة، ولا يظهر في إعدادات الواجهة أو الردود.
