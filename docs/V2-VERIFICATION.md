أهم سيناريوهات التكامل: حفظ وثيقة واسترجاعها، ملف 5MB، منع التكرار، رفض رقم مراجعة قديم، لقطة حزمة ثابتة، تواريخ الدخول والخروج، ما قبل الوصول، الصلاحيات، إبطال جاهزية تغيّر ملفها، حفظ افتراضات القرار، وإلغاء الجلسة فورًا. اختبارات SQLite تتحقق من حفظ قبل/بعد مع العملية ومنع الكتابة بلا سياق ومنع تعديل سجل يقين أو حذفه.

معرف نشر Cloudflare: `c5962347-50ed-4f5d-980f-0f0112663bd1`.

الأصل محفوظ في مجلده وWorker وقاعدته. مرجعه أثناء التحقق: `934aa93fbb2032875ee68b3fd6c08bc19eba6344`، وشجرة عمله نظيفة.

الملفات داخل `work` خاصة ولا تدخل المستودع أو ZIP. يتضمن `docs/verify-workflow.example.yml` قالبًا اختياريًا لتشغيل الاختبارات في GitHub Actions. لم يُفعّل تلقائيًا لأن اعتماد GitHub الحالي لا يملك صلاحية `workflow`. الاختبارات الموثقة أعلاه محلية وعلى الموقع المنشور وليست نتيجة CI.

اختُبر كذلك تحميل النموذج الدلالي المحلي من الواجهة وظهر بحالة مفعّل دون مفتاح API. أُصلح فهم المقارنة العامية «وين يختلف المكتوب في نسخة المستند عن معلومات الوصول»، وأضيف اختبار يمنع تفسيرها كطلب عرض جواز فقط؛ تحققت الإجابة الصحيحة في الواجهة وعلى الموقع المنشور.
